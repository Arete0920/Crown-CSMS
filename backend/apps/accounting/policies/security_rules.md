# ACCOUNTING SECURITY RULES

1. ALL ACCOUNTING ENDPOINTS REQUIRE RBAC.

2. MFA REQUIRED FOR:
   - refunds
   - reversals
   - write-offs
   - exports

3. ALL EXPORTS REQUIRE AUDIT LOGGING.

4. ACCOUNTING APIs REQUIRE RATE LIMITING.

5. EVERY FINANCIAL REQUEST MUST INCLUDE:
   - correlation id
   - authenticated actor
   - tenant validation

6. PRIVILEGED ACTIONS REQUIRE RE-AUTH.

7. FINANCIAL REPORTS MUST BE TENANT SCOPED.

8. RAW SQL ACCESS IS FORBIDDEN.

9. DEBUG MODE MUST NEVER EXPOSE FINANCIAL DATA.

10. ALL FAILED ACCOUNTING AUTH EVENTS MUST BE LOGGED.
