# SOLOMON Governance Corpus C1-A

Purpose:
Collect and index governance-related sources for future SOLOMON demonstration and governed ingestion planning.

This corpus is source-index only. It is not active SOLOMON ingestion.

## Allowed

- source discovery
- source indexing
- URL recording
- ownership classification
- trust-level assignment
- canonical/advisory labeling
- public PDF/Word file collection when legally available

## Not Allowed

- ingestion into SOLOMON models
- AI summarization
- automated classification
- semantic indexing
- vectorization
- copyrighted content replication
- claiming external sources are CROWN-owned

## Trust Levels

- A = Internal canonical or approved CROWN/Arete-authored source
- B = Trusted external governance/accreditation source
- C = Advisory reference
- D = Legacy or low-authority example

## Current Posture

Index-only. Human governance review is required before activation.

## Initial Collection Categories

- accreditation
- board governance
- school handbooks
- policy examples
- Christian school associations
- Arete canonical drafts
