# SOLOMON Source Corpus

Purpose:
Controlled source collection and governance-preparation workspace.

Allowed:
- collect source files
- classify documents
- record ownership
- record trust level
- identify canonical vs advisory sources

Not allowed:
- ingestion into SOLOMON models
- automated summarization
- automated classification
- semantic indexing
- vectorization
- Teams/SharePoint sync
- curriculum publisher ingestion

Trust levels:
- A = Canonical
- B = Operationally Trusted
- C = Advisory
- D = Legacy / Historical
