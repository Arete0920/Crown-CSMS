Creates courses, sections, and enrollments before seed_category_weights, fixing academics validation blocker.

## Problem
- OPS reset ran `seed_category_weights` but no sections/enrollments existed in DEV
- `seed_category_weights` requires sections with enrollments (roster_count > 0)
- `golden_path_bootstrap` only creates admissions data (no academics)
- Result: 0 categories seeded, academics validation blocked (Step A2 failed)

## Solution
**New management command:** `seed_academics_demo.py`
- **Idempotent:** Uses `get_or_create()` for all models (BUILD_RULES.md 3.5 compliant)
- **Deterministic:** Fixed course codes (MATH-101, ENG-101), term (2026-SPRING)
- **Creates:**
  - 2 courses with fixed codes
  - 2 sections (one per course, Spring 2026 term)
  - 25 demo students (households.Student) if none exist
  - 50 enrollments (25 students × 2 sections)

**OPS Workflow Integration (system_views.py):**
```
1. migrate
2. golden_path_bootstrap (admissions)
3. seed_academics_demo (courses/sections/enrollments) NEW
4. seed_category_weights (categories for sections)
```
