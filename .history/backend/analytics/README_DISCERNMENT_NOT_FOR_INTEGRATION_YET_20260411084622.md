# Crown Discernment Integration Hold

## Status
Do not integrate into production yet.

## Reason
The product architecture is being finalized.

Approved direction:
- Crown Compass is the strategic add-on
- Discernment is the explainable predictive engine inside Compass
- Crown Solomon is the guidance and implementation layer

## Current Rule
Any existing or proposed analytics code for Discernment is conceptual until:
- product canon is approved
- data contracts are reviewed
- governance principles are approved
- v1 scope is narrowed
- implementation plan is formally approved

## This Means
Do not:
- wire Discernment into production dashboards
- present conceptual analytics as release-ready
- merge hidden dependencies into Core
- position predictive output as autonomous decision-making

## Temporary Next Step
Keep conceptual analytics isolated and documented while product canon and governance rules are finalized.
