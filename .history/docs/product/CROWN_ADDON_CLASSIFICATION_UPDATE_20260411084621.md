# Crown Add-on Classification Update

## Official Update
The following product structure is now official for this domain:

### Add-on Product
- Crown Compass

### Internal Engine Inside Add-on
- Discernment Engine

### Support / Knowledge / Guidance Layer
- Crown Solomon

## Classification Reason
This structure preserves:
- Crown Core integrity
- add-on boundary discipline
- mission-aware positioning
- safe governance language
- future implementation flexibility

## Why Discernment Is Not Standalone
Discernment is powerful but too abstract to lead as a top-level buyer-facing product.

It works best as the engine inside Compass because:
- Compass is the visible strategic metaphor
- Discernment explains how Compass derives insights
- Solomon helps administrators and boards use it responsibly

## Rule Going Forward
Any future predictive analytics, scenario modeling, or explainable institutional forecasting for this family must be classified under Crown Compass unless explicitly re-approved by canon.
