# Controlled Pilot Acceptance Criteria

Pilot is required before broad GA.

## Entry criteria
- Governance score 95+
- Security score 95+
- Tenant isolation score 97+
- Engineering score 95+
- Product workflow score 95+
- Compliance score 95+
- Public release authority aligned
- Known limitations disposition complete

## Exit criteria
- 14 consecutive days without critical incident
- 0 unresolved critical/high defects
- 0 tenant isolation failures
- 0 data-loss events
- 0 unauthorized access events
- Backup/restore test passed
- Rollback test passed
- Support workflow tested
- Incident response workflow tested
- Founder/Product Owner final GA acceptance signed after pilot
