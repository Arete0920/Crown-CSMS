# Release Authority Checklist

| Item | Required final state | Status | Evidence |
|---|---|---|---|
| VERSION | crown-1.0.0 or approved release identifier | Pending | VERSION |
| Git tag | v1.0.0 or approved pilot tag | Pending | git tag |
| GitHub Release | Current release published | Pending | gh release list |
| README | Matches release status | Pending | README.md |
| PUBLIC_REPO_STATUS | Matches release status | Pending | docs/PUBLIC_REPO_STATUS.md |
| KNOWN_LIMITATIONS | Closed/dispositioned | Pending | docs/KNOWN_LIMITATIONS.md |
| Release notes | Current and complete | Pending | docs/RELEASE_NOTES.md |
| Founder signoff | Committed | Pending | signoff/founder_acceptance.md |
| Post-deploy proof | Committed after deployment | Pending | pilot/postdeploy |

Rule:
Release authority score remains below 100 until every public and internal release artifact agrees.
