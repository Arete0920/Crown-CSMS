# Crown Discernment Technical Position

## Status
Official technical-position canon.

## Product Placement
Crown Discernment is the predictive analytics and scenario engine inside Crown Compass.

It is not a separate top-level Crown product.
It is not part of Crown Core.

## Current Build Status
Conceptual only.
Not approved for production integration yet.

## Approved Technical Direction
Crown Discernment may eventually use:
- transparent statistical methods
- explainable machine learning
- forecast models
- scenario simulation logic
- auditable feature-attribution methods
- model-run persistence
- governance-controlled thresholds and assumptions

## Explainability Standard
Explainability is mandatory.

Approved explanatory methods may include:
- feature contribution analysis
- local explanation views
- global factor summaries
- scenario delta explanations
- assumption tracing
- sensitivity analysis

If SHAP is used, it should be treated as an implementation method, not the public product identity.

## Public Product Language Rule
Do not market the product as:
- “SHAP platform”
- “AI oracle”
- “autonomous predictive engine”

Preferred language:
- explainable predictive analytics
- auditable scenario modeling
- transparent institutional forecasting
- governance-defined intelligence
- mission-aligned decision support

## Technical Boundary Rules
Discernment may consume governed data from Core and modules through explicit interfaces only.

Discernment must not:
- become the canonical owner of student truth
- silently mutate Core data
- create hidden coupling to unrelated systems
- bypass permissions and governance rules
- become mandatory for Crown Core operation

## Safe Initial Use Cases
Potential v1 use cases:
- enrollment forecasting
- attrition or retention indicators
- attendance-linked support indicators
- academic early-warning support indicators
- tuition / aid scenario modeling
- board-facing scenario summaries

## Prohibited or Deferred Use Cases
Do not implement in early phases:
- spiritual scoring
- moral scoring
- automated denial workflows
- automated discipline actions
- autonomous recommendations without human review
- any direct production action triggered purely by model output

## Implementation Readiness Rule
No runtime integration may begin until:
1. Compass canon is approved
2. Solomon canon is approved
3. Discernment principles are approved
4. data contracts are reviewed
5. governance language is approved
6. a v1 narrow scope is chosen
7. testing and audit requirements are written

## Canonical Summary Statement
Discernment is a governed, explainable engine inside Crown Compass. It must remain transparent, auditable, parameter-bound, and subordinate to human judgment.
