# Data Retention and Deletion Proof Standard

Retention policy is complete only when execution is provable.

For each regulated or customer-controlled data class, Crown must be able to identify:

- authoritative source;
- retention rule;
- archival behavior;
- deletion/destruction action;
- exception or legal-hold behavior;
- audit/certificate evidence;
- restore implications.

Automated retention jobs must be tenant-scoped, dry-run capable where appropriate, and covered by tests that prove both deletion eligibility and preservation of records that are not eligible.
