# Certification Pass Criteria (2026-05-30)

Purpose: explicit gate criteria for declaring COMPLETE/PROVEN certification state.

## Required Conditions

1. Authority integrity: canonical authority stack validators pass with zero violations.
2. Security integrity: protected-prefix, tenant, and permission contract suites pass.
3. Readiness integrity: ready routes/wizards/dashboards are fail-closed and evidence-bound.
4. Data-spine integrity: canonical ownership maps and duplicate-truth detectors pass.
5. Certification infrastructure: module/dashboard/wizard/persona matrices and not-proven register are published and machine-validated.
6. Release evidence integrity: artifact naming standard and active evidence packet index pass policy validation.

## Pass Verdict Rule

- Verdict is PASS only when all required conditions above are green in the same candidate window.
- Any single red/open condition forces status to NOT_PROVEN.
