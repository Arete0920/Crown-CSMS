# Priority #10 Strategic Optionality and Financeability Canon

Status: Transaction-readiness governance policy
Updated: 2026-04-14

## Purpose

Define the final governance layer that preserves strategic optionality while Crown scales.
Priority #10 ensures Crown can credibly choose among independent growth, majority-control recapitalization, follow-on raise, or eventual acquisition from strength.

## Priority Stack (Authoritative)

1. Core proof and release path
2. First-wave modules
3. Second-wave operational modules
4. First-wave add-ons and differentiators
5. Packaging, governance, and pilot-readiness
6. Later add-ons and standalone-capable expansion products
7. Implementation, support, integrations, and scale operations
8. Partnership-led market capture and expansion
9. Moat protection, retention discipline, payment-routing enforcement, and enterprise-value compounding
10. Strategic optionality, diligence readiness, and transaction strength

## 10A. Flexible Transaction Structure

Current default posture is structured flexibility, not forced outcome:

1. Majority-control recapitalization remains a credible primary structure
2. Staged capital release is tied to milestone evidence
3. Founder rollover and incentive alignment are explicit
4. Investor governance controls are defined without disabling operator execution
5. No forced sale narrative before commercialization proof is complete

## 10B. Diligence Package Completeness

Maintain an always-ready diligence packet containing at minimum:

1. Branch-protection and required-check enforcement evidence
2. Production-complete module inventory and status truth
3. Live admissions -> enrollment -> billing -> attendance proof path
4. Executed CompuWerx agreement terms and routing controls
5. School pipeline, pilot status, and LOI evidence register

## 10C. Valuation-Relevant Proof Metrics

Value narrative must be driven by operating proof, not promotional assumptions:

1. Successful pilot execution and conversion
2. Recurring revenue visibility and quality
3. Implementation repeatability and time-to-live discipline
4. Stable release and delivery performance
5. Expansion gating tied to proven traction thresholds

## 10D. Investor Language Discipline

Messaging must remain evidence-aligned:

1. Use credible-operating-MVP framing until all launch gates are fully green
2. Separate proven, in-progress, and deferred scope in every investor artifact
3. Avoid full-completion claims that outpace evidence
4. Keep transaction narrative grounded in staged commercialization proof

## Optionality Rule

Crown must remain decision-flexible at all times:

1. Independent operating company path remains viable
2. Majority-control recap path remains execution-ready
3. Follow-on raise path remains supportable with metrics
4. Eventual acquisition path remains negotiable from strength, not urgency
