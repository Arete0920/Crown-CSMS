# Tier 0 Internal Sandbox Plan

**Audience:** TC and first internal team of five
**Purpose:** confirm that CROWN is ready for controlled external sandbox review.

## Tier 0 goals

1. Confirm all five users can sign in.
2. Confirm the correct sandbox school context is visible.
3. Confirm dashboard navigation and key workflows are understandable.
4. Confirm issue intake and daily triage work before inviting VIP schools.
5. Confirm the known-limitations language is clear.

## Five-user review pattern

| Reviewer | Primary focus |
|----------|---------------|
| TC | Overall product fit, positioning, leadership dashboard flow |
| Internal reviewer 2 | Login, school context, navigation, dashboard access |
| Internal reviewer 3 | Admissions, enrollment, registrar, and student workflows |
| Internal reviewer 4 | Billing, financial aid, revenue operations, advancement |
| Internal reviewer 5 | Wizards, support intake, issue triage, documentation clarity |

## Day 1 checklist

- Login works.
- Correct sandbox school context appears.
- Main navigation loads.
- Dashboard list is understandable.
- Known-limitations notice is visible or linked.
- Feedback channel is working.

## Day 2 checklist

- Admissions and enrollment workflows reviewed.
- Attendance, registrar, and gradebook dashboards reviewed.
- Billing, financial aid, and revenue dashboards reviewed.
- Communications and school administrator dashboards reviewed.
- Wizard entry points reviewed.

## Exit gate to Tier 1

Tier 1 may begin only when:

- No critical login issue is open.
- No tenant visibility concern is open.
- No dashboard access regression is open.
- No wizard issue blocks broad evaluation.
- The feedback intake process is working.
- The internal team agrees VIP reviewers will receive clear instructions.
