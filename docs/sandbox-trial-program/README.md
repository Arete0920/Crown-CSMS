# CROWN Sandbox Trial Program

**Status:** controlled sandbox program planning
**Product:** CROWN - Christian School Management Solution
**Created:** 2026-06-22

## Purpose

The CROWN Sandbox Trial Program is a controlled evaluation program for internal staff, VIP prospects, buyers, partners, and interested schools. It validates onboarding, usability, dashboard value, workflow clarity, support intake, and feedback quality before any broad rollout.

This is a sandbox trial program, not a production launch.

## Launch sequence

| Tier | Audience | Size | Purpose |
|------|----------|------|---------|
| Tier 0 | TC and internal team | 5 users | Confirm access, flows, support, and triage |
| Tier 1 | VIPs, buyers, partners | 15 schools or teams | Validate external usability and buyer confidence |
| Tier 2 | Engaged early schools | 35-50 schools | Validate support load and school variety |
| Tier 3 | Broad pilot cohort | 75-90 schools | Validate wider adoption patterns |
| Tier 4 | Remaining interested schools | Remaining cohort | Complete staged sandbox access |

## Advancement rule

Advance only when the current tier has no active critical access issue, no tenant visibility concern, no dashboard regression, no majority-blocking wizard issue, and a functioning support triage rhythm.
