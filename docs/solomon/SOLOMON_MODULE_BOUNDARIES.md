# SOLOMON Module Boundaries

Status: Planning Only

## SOLOMON Owns

- institutional knowledge
- resource taxonomy
- curriculum/resource metadata
- scripture/devotional resource metadata
- policy and governance references
- contextual help/playbook structure
- role/audience targeting
- source/version/review metadata

## CROWN Owns

- operational workflows
- student records
- admissions
- billing
- financial aid
- attendance
- communications
- parent/student/teacher portals
- reporting
- tenant enforcement

## Microsoft Owns

- Entra identity
- Teams collaboration
- SharePoint/OneDrive document storage
- Outlook/Calendar productivity
- Microsoft 365 document workflows

## SOLOMON Must Not Own

- raw operational transactions
- billing execution
- admissions decisions
- tenant security enforcement
- user authentication
- Microsoft document-editing functions
- production release gates

## Boundary Rule

CROWN executes.
SOLOMON informs.
Microsoft collaborates.
Governance controls.
