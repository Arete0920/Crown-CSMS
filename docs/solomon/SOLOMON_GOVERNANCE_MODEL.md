# SOLOMON Governance Model

Status: Planning Only

## Required Governance Fields

Every future SOLOMON resource should support:

- title
- slug
- summary
- content/reference
- category
- topic
- audience
- visibility
- status
- owner
- approver
- review_date
- version
- source_url
- license_type
- publisher
- school_scope
- created_at
- updated_at

## Status Values

- draft
- approved
- published
- archived

## Governance Rules

1. No unapproved canonical content.
2. No publisher content ingestion without rights.
3. No cross-tenant resource exposure.
4. No spiritual-life content without review/approval.
5. No curriculum resource marked canonical without ownership.
6. No production module may rely on draft SOLOMON content.
