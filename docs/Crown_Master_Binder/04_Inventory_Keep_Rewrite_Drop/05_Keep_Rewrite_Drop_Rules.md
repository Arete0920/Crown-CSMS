# Keep / Rewrite / Drop Rules

## Keep
Use only if it is:
- correct
- clean
- testable
- reusable
- aligned with canons

## Rewrite
Use when:
- concept is right
- implementation is messy, stale, inconsistent, or overbuilt

## Drop
Use when:
- duplicate
- outdated
- abandoned
- demo-only
- scope bloat
- experiment with no future place

## Rule
Nothing gets deleted before inventory is complete.
