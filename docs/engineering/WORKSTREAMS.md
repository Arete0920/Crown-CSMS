# CROWN Workstream Register — Superseded Historical Record

**Status:** SUPERSEDED / HISTORICAL — NOT CURRENT WORK AUTHORITY  
**Current authority:** GitHub issues/pull requests together with `docs/CURRENT_RELEASE_STATUS.md` and `docs/canonical/CANONICAL_DOCUMENT_INDEX.md`

## Disposition

The former register mapped predecessor-era issue numbers and workstreams as active Crown work. That snapshot no longer represents current Crown-CSMS execution state and must not be used to reopen completed engineering work or classify current release blockers.

The former body remains available in Git history for provenance.

## Current use

- Use current Crown-CSMS issues and pull requests for live work status.
- Use `docs/CURRENT_RELEASE_STATUS.md` for current release, payment, recovery, and turnover posture.
- Use `docs/canonical/DILIGENCE_EVIDENCE_INDEX.md` for current evidence-navigation boundaries.
- Treat predecessor issue IDs from the former register as historical unless a current canonical record explicitly adopts them.

Do not infer production deployment, operational turnover, payment readiness, legal/compliance certification, or independent human review from historical workstream records.
