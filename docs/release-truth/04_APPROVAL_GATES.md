# Approval Gates

| Gate | Meaning | Who Can Mark It | Required Evidence |
|---|---|---|---|
| Draft | Working content only | Lane owner | None |
| Stable Draft | Internally coherent | Lane owner + reviewer | Local proof or review note |
| Approved Working Authority | Team may build against it | Responsible lead + TC | Evidence attached |
| Final Release Authority | Controls final release claim | TC only | Green release gate + linked evidence |

## Rule
No file, module, workflow, or release claim may be treated as final without Final Release Authority.
