# Naming and File Location Rules

## Canonical Folder
All release-truth files live in:
docs/release-truth/

## Naming
- 00_ prefix = controlling directive
- 01_ prefix = required gate
- 02_ prefix = superseded register
- 03_ prefix = release truth matrix
- 04_ prefix = approval gates
- 05_ prefix = RACI
- 06_ prefix = risk register
- 07_ prefix = scorecard
- evidence/ = artifacts only

## Rule
No release-truth file may live at repo root.
No draft file may use the word FINAL in its name unless TC approved it.
