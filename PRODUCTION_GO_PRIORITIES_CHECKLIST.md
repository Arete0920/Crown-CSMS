## Phase 1: Unlock Production GO (REQUIRED)

### 🚨 Priority 0️⃣-A — Fix deploy-prod.yml Heredoc Bug (CRITICAL BLOCKER)

**Timeline:** < 30 minutes  
**Owner:** Release Engineering (authorized workflow editor)  
**Status:** 🔴 CRITICAL — deploy-prod HAS NEVER SUCCEEDED

**Root Cause (verified 2026-05-06):**

In `.github/workflows/deploy-prod.yml`, step `"Guard: Azure auth secrets present"`, the
bash heredoc terminator `PY` has leading spaces due to YAML block indentation.  
Bash heredoc terminators must be at **column 0** unless `<<-` with tabs is used.  
Result: every deploy-prod run fails with `line 43: syntax error: unexpected end of file`
before Azure login is even attempted.

**Evidence:**

- Run `25139353890` (2026-04-29): `Process completed with exit code 2.`
- All 10 available runs: failure, cancelled, or stuck `waiting`
- Confirmed by reading `.github/workflows/deploy-prod.yml` lines 85–109

**Required Fix (requires explicit authorization to edit protected workflow):**

In `deploy-prod.yml`, replace the space-indented heredoc block in the
`"Guard: Azure auth secrets present"` step with an equivalent `python3 -c` invocation.
This removes the dependency on heredoc column-0 terminator placement.

**Authorization Gate:** Do not edit this file without explicit release engineer approval.
Once authorized, this is a ~10-line change that unblocks all future deploys.

**Blocker Resolution:** Once fixed and a `prod-deploy-*` tag is pushed from a clean main
commit, deploy-prod.yml will proceed past the auth guard step for the first time.
